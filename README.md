## Innihald

- verkefni og lausnir
- kóðadæmi og tilraunir
- glósur og önnur gagnleg skjöl

## Skipulag

Möppur og skrár eru settar upp eftir verkefnum eða viðfangsefnum eftir því sem efnið bætist við.

Opnaðu viðeigandi verkefnamöppu og fylgdu þeim leiðbeiningum sem fylgja verkefninu. Kröfur um hugbúnað, uppsetningu eða keyrslu geta verið mismunandi eftir verkefnum.

Lugia - Pokemon X/Y game model replacement

Replaces the earlier statue-based Lugia. The game model mesh, original skeleton and original skin weights are preserved.
lugia.glb: rig, embedded textures, Idle and Attack_Ranged. No physical attack.
Idle: 4-second looping wing flap, small head bob and hover.
Attack_Ranged: 3.2-second flying backflip and ranged release at 2.0 seconds. Play once and blend back to Idle.
source/lugia_animated.blend: editable Blender file with packed textures and both actions.
source/: original game rip; textures/normal and textures/shiny: original texture sets.
Original rip: Random Talking Bush; see source/Tag.txt for credits and copyright information.
Source page: https://models.spriters-resource.com/3ds/pokemonxy/asset/291953/page-1/
The attack and idle are new authored motions, not extracted game animations. No projectile effects.
GLB uses Y-up; 30 FPS. Model scale follows the other converted game models.
The original game bind pose is unchanged. The statue mesh is not used in this package.

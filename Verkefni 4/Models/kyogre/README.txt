kyogre: rigged model with two original attack motions

kyogre.glb contains the weighted skeleton, embedded textures and both named animation clips.
Attack_Physical: 1.6 seconds, wind-up / strike / recovery; impact at 0.667 seconds.
Attack_Ranged: 2.4 seconds, charge / release / recovery; release at 1.2 seconds.
30 FPS. Both return to the starting pose. Play attacks once, with looping disabled.
Motions include transient body movement and return to the initial position. No projectile or particle effects.
source/kyogre_animated.blend is editable. Choose an action in the Dope Sheet Action Editor.
source/ also preserves the original supplied files; textures/ preserves supplied texture sets.
Existing game skeleton and skin weights preserved.
The GLB is Y-up. Original input model scale is retained. No engine-specific humanoid retargeting or IK control rig.

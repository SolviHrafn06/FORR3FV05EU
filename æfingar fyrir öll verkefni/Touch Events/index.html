FORR3FV05EU / POINTER EVENTS

Prófaðu með fingrunum.

Lítil tilraunastofa fyrir mús, snertiskjá og penna. Fylgstu með því hvað gerist í kóðanum.

01 · Teiknaðu

Dragðu yfir flötinn. Prófaðu marga fingur samtímis; hver snerting fær sinn lit. Þrýstingur penna breytir línuþykkt.

Vafrinn þarf að styðja canvas.

pointerdown → pointermove → pointerup · Map geymir virkar snertingar.

02 · Hreyfðu og snertu

Ýttu stutt, tvíýttu eða haltu í 600 ms. Dragðu með einum fingri eða strjúktu hratt (swipe). Með tveimur fingrum geturðu stækkað, minnkað og snúið.

03 · Hvað sér JavaScript?

Viðburðaskrá

    Skráin sýnir síðustu 12 viðburði. pointermove birtist í hnitunum til að skráin fyllist ekki.

    Hvernig prófa ég þetta?
    1. Í tölvu: Opnaðu index.html í vafra. Notaðu mús til að teikna, draga, tvísmella og halda inni.
    2. Hermdur snertiskjár: Opnaðu Developer Tools (F12), kveiktu á device toolbar og veldu síma. Prófaðu eins fingurs hreyfingar.
    3. Í síma: Opnaðu möppuna í VS Code, ræstu Live Server á porti 5500 og notaðu VS Code Port Forwarding. Opnaðu áframsenda slóð í símanum og skráðu þig inn ef beðið er um það.
    4. Multitouch: Prófaðu tveggja fingra stækkun og snúning á raunverulegum snertiskjá. Mús ein og sér sendir ekki tvær samtímis snertingar.

    Í script.js eru skýringar við Map, setPointerCapture(), hnit og hreyfingar. CSS-reglan touch-action: none á prófunarflötunum leyfir demóinu að sjá um snertihreyfingar. Þú getur skrunað síðunni utan þeirra.
